Query: SELECT * FROM orders WHERE warehouse_id = 1;

--- FIRST RUN - BEFORE INDEX ---

  Filter: (warehouse_id = 1)
Planning Time: 0.120 ms
Execution Time: 0.045 ms

--- CREATE INDEX ---
CREATE INDEX idx_orders_warehouse_id ON orders(warehouse_id);

--- SECOND RUN - AFTER INDEX ---
Index Scan using idx_orders_warehouse_id on orders  (cost=0.15..8.17 rows=2 width=32)
  Index Cond: (warehouse_id = 1)
Planning Time: 0.110 ms
Execution Time: 0.021 ms

Conclusion: After index, planner changed from Seq Scan to Index Scan. Execution time reduced.
